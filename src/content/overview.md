# ミッションボード

**Mission Based Idea Helper** — プログラミング教室向けのミッション管理 Web アプリ

---

## システム概要
プログラミング教室における子供たちのアイデア不足の解消を図るために導入したミッション管理Webアプリケーションです。

---

## 主な機能

### ミッション一覧

- Scratch・Unity・LEGO SPIKE・3Dペン・Blender など、コースごとにミッションを整理
- 難易度（★1〜★9）・タイプ（機能系・思考系・体験系など）でわかりやすく分類
- ミッションのクリア登録と参加人数をリアルタイムで追跡

### ダッシュボード統計

- ミッション総数・クリア総数・アクティブ数をリアルタイム集計
- クリア登録を画面下部でスクロール表示する「クリアティッカー」

### 作品紹介

生徒の制作作品をカード形式で紹介・共有できます。

### ミッション依頼

- 生徒・一般ユーザーが新しいミッションをリクエスト可能
- 先生（Admin）が依頼を確認し、ミッションとして承認・追加

### 管理機能（Admin）

- ミッションの追加・編集・削除
- 依頼の承認・却下・PIN 管理
- Google スプレッドシートとのデータ連携

---

## 対応コース

| コース | 内容 |
|--------|------|
| Scratch | ビジュアルプログラミング |
| Unity | ゲーム・インタラクティブコンテンツ制作 |
| LEGO SPIKE Basic | ロボットプログラミング（入門） |
| LEGO SPIKE Prime | ロボットプログラミング（応用） |
| 3Dペン | 3D アート・立体造形 |
| Blender + 3D造形 | 3D CG モデリング |

---

## ミッションの種類

| タイプ | 内容 |
|--------|------|
| 機能系 | 特定の機能を実装するミッション |
| 思考系 | アルゴリズムや論理的思考を問うミッション |
| 体験系 | 新しい技術や表現を体験するミッション |
| 技術縛り系 | 特定の技法・制限の中で制作するミッション |
| 社会テーマ系 | 社会課題や環境をテーマにしたミッション |
| その他 | 上記に当てはまらないオリジナルミッション |

---

## テーマ

暖色（デフォルト）・寒色・ダークの 3 テーマに対応しています。右上の設定メニューから好みに合わせて切り替えられます。

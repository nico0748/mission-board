# 背景

## 開発のきっかけ

プログラミング教室では、生徒ごとに取り組むミッションの管理や進捗の可視化が難しいという課題がありました。紙のリストや口頭での管理では、クリア記録の把握や生徒のモチベーション維持が困難になりがちです。

この課題を解決するために、ブラウザだけで動作するシンプルなミッション管理ダッシュボードとして開発しました。

---

## 解決したかった課題

- **ミッションの可視化** — どのミッションがあるか、どれが人気かを一目で把握したい
- **クリア記録の管理** — 誰が何のミッションをクリアしたか記録・表示したい
- **生徒のモチベーション** — クリア通知や統計で達成感をクラス全体と共有したい
- **先生の作業軽減** — ミッションの追加・編集を UI から簡単に操作したい
- **既存ツールとの連携** — 使い慣れた Google スプレッドシートと連動して使いたい

---

## 対象ユーザー

| ロール | 説明 |
|--------|------|
| 一般（生徒・保護者） | ミッション閲覧・依頼の送信 |
| Admin（先生） | ミッション管理・依頼の承認・クリア登録 |

Admin は PIN 認証で切り替えられます。認証後は管理パネルが表示され、ミッションの CRUD や依頼レビューが可能になります。

---

## 開発の流れ

当初はモックデータ（`data/seed.ts`）でプロトタイプを作成し、UI や操作感を確認しました。その後、Google スプレッドシートとの API 連携を追加することで、実際の教室環境での運用に対応しました。
